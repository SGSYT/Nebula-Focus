# 🌌 NebulaFocus

A minimalist, frosted-glass Pomodoro productivity app built with a deep-space aesthetic, circular rotary dial controls, offline Web Audio soundscapes, and anti-distraction Orbit Lock.

## ✨ Features
- **Interactive Circular Dials:** Smooth 360° touch and cursor rotary dials for custom Work, Rest, and Cycle routines.
- **Anti-Distraction Orbit Lock:** Detects app/tab switches during active focus sessions and triggers a 5-beep alert.
- **Offline Cosmic Soundscapes:** Synthesized Space, Brown Noise, Pink Noise, and Rain audio using the Web Audio API (zero external audio files).
- **Mission Task Splitter:** Breaks goals into actionable Pomodoro sprints saved locally on your device.
